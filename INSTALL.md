# Равно 1.0.0 — установщик для Windows x64

Бесплатное приложение для личных и рабочих финансов. Русский интерфейс, локальное хранение данных на компьютере, без обязательной регистрации.

## Установка

1. Запустите Ravno-Setup-1.0.0-x64.exe.
2. Выберите каталог для установки. Установка выполняется для текущего пользователя.
3. После завершения откройте «Равно» через ярлык на рабочем столе или в меню «Пуск».

Эта сборка не подписана платным сертификатом. Windows может показать предупреждение о неизвестном издателе; на компьютерах с отдельными политиками безопасности запуск может быть заблокирован. Не отключайте защиту ради установки.

## Данные и удаление

Данные хранятся локально. Перед переносом на другой компьютер создайте резервную копию в приложении. Удаление через «Установленные приложения» удаляет программу и ярлыки, сохраняя пользовательские данные; повторная установка получает доступ к ним. Это поведение проверено в одноразовой Windows 11 на синтетических данных.
